# Bar de Pueblo Tycoon

Juego de gestión: lleva el bar del pueblo con precios, género, mejoras, camareros y los eventos del calendario.

Sitio: https://adrianezd.github.io/bar-de-pueblo/

Toda la economía (precios de referencia, mejoras y eventos) está al principio de `script.js`. La partida se guarda en localStorage.
